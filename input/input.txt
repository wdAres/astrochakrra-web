PROJECT BRIEF — AstroChakrra
A React.js single-page website for a Vedic astrologer.

----------------------------------------------------------------
VISION
----------------------------------------------------------------

Build a calm, premium, highly accurate landing page for AstroChakrra
("Vedic Wisdom for a Balanced Life"). The site should feel like a
private consultation room: warm, trustworthy, and composed — never
loud, never cluttered.

A visitor should immediately understand:
  1. Who this is for (people seeking clarity on marriage, career,
     family, vastu, numerology, and timing).
  2. Who the astrologer is and why they can be trusted.
  3. How a consultation works, what services exist, and what
     packages they can book.
  4. How to book in one click, from any section of the page.

Every CTA leads to one booking modal. Every card and package
pre-fills the relevant service. All content comes from a single
data file so the site can later connect to an API without
rewriting the UI.

UI DESIGN
  Follow input-fe.jpeg in this folder as the source of truth for
  layout, typography, spacing, colour, and overall visual language.
  Desktop and mobile compositions are both shown in that file —
  match them closely.

----------------------------------------------------------------
TECHNICAL APPROACH
----------------------------------------------------------------

- Deliver as a React.js single-page application (SPA).
- One page, smooth in-page scroll. Navbar links jump to sections.
- Structure the app as reusable section components.
- Keep everything programmatically correct so an API can be
  connected later with minimal change.
- Drive the site from a single data file (for example
  src/data/siteData.js). Populate at least these from that file:
    • service cards
    • consultation packages
    • testimonials
    • FAQs
    • navigation items
    • trust points
    • consultation process steps
    • “what brings you here” topic cards
  Components must map over this data. Do not hardcode card lists
  inside JSX.
- Make the entire site highly responsive. Mobile must include a
  sidebar / drawer navigation.
- Add a fixed floating WhatsApp button at the bottom-right on
  every viewport.

----------------------------------------------------------------
COLOUR THEME
----------------------------------------------------------------

Use the palette from the reference image:

  Cream / ivory page background
  Soft parchment / beige section fills
  Deep navy / charcoal for dark bands and headings
  Gold / warm metallic for accents, borders, icons, and CTAs
  White cards with subtle gold or ink outlines
  Warm brown / ink body text

Do not invent a new palette. The theme is astrology-related:
lotus motifs, fine gold line work, and a quiet, editorial feel.

----------------------------------------------------------------
BOOKING MODAL
----------------------------------------------------------------

One shared modal for every CTA, service card, and package button.

Fields:
  - Name
  - Email
  - Query (message / what they want guidance on)
  - Service — a select dropdown listing every service type

Behaviour:
  - Navbar / hero / footer CTA → modal opens with no service
    pre-selected (or a sensible default).
  - Clicking a service card → modal opens with that service
    already selected.
  - Clicking a package “Book Now” → modal opens with the
    matching service / package already selected.
  - Each card maps to its own service type in the modal list.
  - Form should be ready to submit to an API later; for now
    it can log / store locally or show a success state.

----------------------------------------------------------------
QUALITY BAR
----------------------------------------------------------------

Make the site look accurate, polished, and cool — a premium
astrology brand, not a generic template.

- Pixel-aware spacing, consistent type scale, refined cards.
- Decorative graphics that support the theme (lotus, gold
  lines, subtle texture) without cluttering content.
- Smooth scroll, tasteful hover states, accessible focus.
- Highly responsive: the mobile layout in the reference image
  is the target for small screens.
- Content, colours, and structure must stay in lockstep
  with input-fe.jpeg.
